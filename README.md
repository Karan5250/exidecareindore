# Exide Care Authorized Dealer SC — Website

This is a static, GitHub Pages-ready website for **Exide Care Authorized Dealer SC, Indore**.

## Files
- `index.html` — Home
- `products.html` — Product categories
- `about.html` — About
- `contact.html` — Contact
- `assets/css/style.css` — Design
- `assets/js/main.js` — Mobile menu / interactions
- `assets/images/logo.jpg` — supplied Exide Care logo

## GitHub upload
1. Open your repository: `Karan5250/exidecareindore`
2. Delete the old website files if you want a clean replacement.
3. Upload all files/folders from this ZIP so that `index.html` is directly in the repository root.
4. Commit the changes.
5. In Settings → Pages, use `main` and `/(root)`.

## Custom domain later
When DNS is ready for `exidecareindore.in`, add the domain in GitHub Pages → Custom domain. Do not add a CNAME file until the domain is being connected.

## Important
Product buttons currently open Exide Care's official product catalogue:
`https://www.exidecare.com/products`

The site does not copy Exide Care's website layout; it uses an original layout and styling while using the dealer-provided Exide Care logo.
